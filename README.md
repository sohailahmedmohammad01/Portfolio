# Mohammad Sohail Ahmed — Portfolio

A personal portfolio built with React, TypeScript, and Vite. It presents Mohammad's backend engineering experience, selected projects, CJSS Technologies recognition, credentials, and contact details.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run lint
npm run build
```

The downloadable résumé is in `public/docs/resume.pdf`. The photographs in `src/images` were provided for this portfolio.
